# 3D assets (integration drop)

This folder is a **receive** box. We do not author Blender files in this repo.

When a teammate exports a model, put it here as `<slug>.glb` or `<slug>_growth.mp4` (slugs in `docs/11-species.md`). The app plays whatever is present and shows a placeholder when the file is missing.

See `docs/08-modules-and-business-logic.md` (M3).
